# Quick Start Guide

## 🚀 Get Started in 30 Seconds

1. **Open the Demo**
   - Double-click `index.html` in this folder
   - Or drag `index.html` into your browser

2. **Wait for Loading**
   - Dashboard loads automatically (2-3 seconds)
   - 3D scene renders with simulated data

3. **Explore the Dashboard**
   - Watch entities move in real-time
   - Click on rooms to highlight them
   - Switch floors using the selector (top-right)

**That's it!** No installation, no backend, no configuration needed.

---

## 📖 What You're Seeing

### Moving Avatars (Entities)
- 🔵 **Blue**: Computer Vision detection only
- 🟢 **Green**: UWB positioning only  
- 🟣 **Purple**: Fused (both CV and UWB)

### Panels
- **Left**: Occupancy dashboard with room counts
- **Top**: Alert banner (appears when alerts trigger)
- **Right**: Analytics and playback controls

### 3D Controls
- **Left Mouse**: Rotate view
- **Right Mouse**: Pan
- **Scroll Wheel**: Zoom
- **Floor Selector**: Switch between floors

## 🐛 Troubleshooting

**Dashboard not loading?**
- Try Chrome or Firefox
- Check browser console (F12) for errors
- Disable ad blockers

**3D view not rendering?**
- Ensure WebGL is enabled
- Update graphics drivers
- Try a different browser

**Slow performance?**
- Close other browser tabs
- Use a computer with dedicated GPU
- Reduce browser zoom to 100%
