🚀 QUICK START (30 seconds)
================================================================================

1. Double-click "index.html" to open in your browser
2. Wait 2-3 seconds for the dashboard to load
3. Watch entities move in real-time on the 3D floor plan

That's it! No installation, no backend, no configuration needed.


📖 WHAT YOU'RE SEEING
================================================================================

This is a fully functional demo of the Command Center BlueIOT Digital Twin
Dashboard running with simulated data. It showcases:

✓ 3D floor plan visualization with real-time tracking
✓ Multi-source data fusion (Computer Vision + UWB positioning)
✓ Occupancy analytics and demographic insights
✓ Real-time alert system with severity levels
✓ Historical playback with timeline controls
✓ Analytics dashboard with trends and heatmaps

💡 KEY FEATURES TO TRY
================================================================================

1. Real-Time Tracking
   - Watch colored avatars move through rooms
   - Blue = CV only, Green = UWB only, Purple = Fused

2. Occupancy Dashboard
   - See live room counts on the left panel
   - Click rooms to highlight them on 3D view

3. Alert System
   - Wait for alerts to appear at the top
   - Click to see affected rooms
   - Acknowledge to mark as handled

4. Analytics
   - Open Analytics panel for trends and heatmaps
   - Switch time ranges (1h, 6h, 24h, 7d)

5. Historical Playback
   - Open Playback panel
   - Select past time range
   - Play at different speeds (1x to 16x)


🖱️ CONTROLS
================================================================================

3D View:
- Left Mouse: Rotate view
- Right Mouse: Pan
- Scroll Wheel: Zoom
- Floor Selector: Switch floors (top-right)

Keyboard Shortcuts:
- Space: Play/Pause playback
- Arrow Keys: Navigate timeline
- 1-3: Switch floors
- F11: Fullscreen mode


🐛 TROUBLESHOOTING
================================================================================

Dashboard not loading?
→ Try Chrome or Firefox browser
→ Disable ad blockers
→ Check browser console (F12) for errors

3D view not rendering?
→ Ensure WebGL is enabled in browser
→ Update graphics drivers
→ Try a different browser

Slow performance?
→ Close other browser tabs
→ Use computer with dedicated GPU
→ Ensure browser zoom is at 100%
