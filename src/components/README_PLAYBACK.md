# Historical Playback Feature

## Overview

The historical playback feature allows users to review past entity movements and activities within the facility. This is useful for incident investigation, traffic pattern analysis, and understanding facility usage over time.

## Components

### PlaybackPanel
- **Location**: `src/components/PlaybackPanel.tsx`
- **Purpose**: Configuration panel for setting up historical playback
- **Features**:
  - Date and time range picker for selecting playback period
  - Quick select buttons (1h, 6h, 24h, 7d)
  - Floor filter to focus on specific floors
  - Room filter to focus on specific rooms
  - Start/Exit playback mode toggle

### PlaybackControls
- **Location**: `src/components/PlaybackControls.tsx`
- **Purpose**: Timeline scrubber and playback controls
- **Features**:
  - Timeline slider for seeking through historical data
  - Play/Pause button
  - Playback speed controls (1x, 2x, 4x, 8x, 16x)
  - Current timestamp display
  - Start/End time indicators

### usePlaybackManager Hook
- **Location**: `src/hooks/usePlaybackManager.ts`
- **Purpose**: Manages playback state and entity updates
- **Features**:
  - Handles playback timing at ~60 FPS
  - Builds entity trajectories (last 30 seconds)
  - Manages play/pause state
  - Handles seeking to specific timestamps
  - Supports variable playback speeds

## Data Generation

### Historical Data Structure
Historical data is generated by `DummyDataGenerator.generateHistoricalData()`:
- Creates time-series snapshots at 100ms intervals (10 Hz)
- Simulates realistic entity movement patterns
- Adjusts entity count based on time of day:
  - Work hours (8am-6pm): 25-40 entities
  - Evening (6pm-10pm): 10-20 entities
  - Night (10pm-8am): 2-8 entities
- Entities spawn and despawn dynamically during the time range
- Supports floor and room filtering

### Trajectory Building
Trajectories are built dynamically during playback:
- Collects last 30 seconds of position data
- Updates in real-time as playback progresses
- Rendered as line paths in 3D scene

## Usage

### Starting Playback
1. Click "Historical Playback" button (top right)
2. Select time range using:
   - Quick select buttons (1h, 6h, 24h, 7d), or
   - Manual date/time inputs
3. Optionally filter by floor and/or room
4. Click "Start Playback"

### During Playback
- **Play/Pause**: Click play/pause button or press spacebar
- **Seek**: Drag timeline slider to jump to specific time
- **Speed**: Click speed buttons (1x to 16x) to adjust playback rate
- **View**: Current timestamp displayed above timeline

### Exiting Playback
- Click "Exit Playback Mode" button
- Returns to live real-time view

## Store Integration

### Playback State
The following state is managed in `src/store/index.ts`:
- `isPlaybackMode`: Boolean flag for playback mode
- `playbackStartTime`: Start timestamp (milliseconds)
- `playbackEndTime`: End timestamp (milliseconds)
- `playbackCurrentTime`: Current playback position (milliseconds)
- `playbackFilterFloorId`: Optional floor filter
- `playbackFilterRoomId`: Optional room filter

### State Actions
- `setIsPlaybackMode(mode)`: Toggle playback mode
- `setPlaybackTimeRange(start, end)`: Set time range
- `setPlaybackCurrentTime(time)`: Update current position
- `setPlaybackFilterFloorId(floorId)`: Set floor filter
- `setPlaybackFilterRoomId(roomId)`: Set room filter

## Performance Considerations

### Data Generation
- Historical data is generated on-demand when entering playback mode
- Large time ranges (7 days) generate ~6 million snapshots
- Generation is synchronous but typically completes in <2 seconds
- Data is stored in memory as a Map for O(1) lookup

### Playback Rendering
- Updates at ~60 FPS for smooth animation
- Only renders entities for current floor
- Trajectories limited to 30 seconds (300 points max)
- Three.js handles efficient 3D rendering

### Memory Usage
- Each entity snapshot: ~200 bytes
- 1 hour playback: ~36,000 snapshots × 30 entities = ~216 MB
- 7 day playback: ~6M snapshots × 30 entities = ~36 GB (not recommended)
- Recommend limiting playback to 24 hours or less
